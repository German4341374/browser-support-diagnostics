# Repository Guidelines

- Keep all source code, comments, documentation, and commit messages in English.
- Preserve the local-only privacy model and minimal Manifest V3 permissions.
- Do not add telemetry, external API calls, host permissions, or third-party
  runtime scripts.
- Use `textContent` rather than HTML injection for page-controlled values.
- Run `npm run check` before committing.
- Follow Conventional Commits.
