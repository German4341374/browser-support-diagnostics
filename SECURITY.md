# Security Policy

## Supported versions

Security fixes are applied to the latest release on the `main` branch.

## Reporting a vulnerability

Use GitHub private vulnerability reporting when available. Do not open a public
issue containing exploit details or sensitive diagnostic output.

Include the affected version, reproduction steps, impact, and a minimal example
that contains no real credentials or personal data. Reports are normally
acknowledged within seven days.

## Security boundaries

The extension produces local diagnostic data; it does not guarantee that a
manually exported report is free from all business-sensitive page titles or
resource paths. Review exports before sharing them. The extension is not a
malware scanner, network proxy, or replacement for browser developer tools.
